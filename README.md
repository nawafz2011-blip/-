# محمّل الفيديوهات

موقع لتحميل الفيديوهات من يوتيوب وتيك توك وإنستقرام وتويتر وفيسبوك ومئات المواقع الثانية. يدعم الجودات من 360p إلى **8K**، ويقدر يحمّل الصوت بس بصيغة MP3.

مبني على:
- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)**: يجيب الفيديو ويحمّله
- **ffmpeg**: يدمج الصوت مع الصورة في الجودات العالية، ويحوّل الصوت لـ MP3
- **FastAPI**: السيرفر
- واجهة HTML عربية بسيطة ما تحتاج أي مكتبات

> يوتيوب يوفر لين 8K كحد أقصى. الموقع يعرض الجودات اللي رفعها صاحب الفيديو بس.

## التشغيل على جهازك

لازم يكون عندك Python 3.10 أو أحدث، و ffmpeg.

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

بعدها افتح http://localhost:8000

## التشغيل بـ Docker (للسيرفر)

```bash
docker build -t video-downloader .
docker run -d -p 8000:8000 --restart unless-stopped video-downloader
```

الحاوية تحدّث yt-dlp تلقائياً كل ما تشتغل، لأن يوتيوب يغيّر موقعه باستمرار.

## الاستضافة

الموقع يحتاج **سيرفر**، فما ينفع على GitHub Pages. خيارات مناسبة:
- **VPS** مثل Hetzner أو DigitalOcean أو Contabo، بحوالي 5 إلى 10 دولار شهرياً. هذا أفضل خيار لأن تحميل 4K و8K يستهلك باندويث ومساحة.
- **Railway** أو **Render** أو **Fly.io**: يقرون الـ Dockerfile مباشرة.

## الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MAX_CONCURRENT_DOWNLOADS` | `3` | أكثر عدد تحميلات في نفس الوقت |
| `MAX_DURATION_SECONDS` | `10800` | أطول مدة فيديو مسموح بها (3 ساعات) |
| `MAX_FILESIZE_MB` | `4096` | أكبر حجم ملف |
| `RATE_LIMIT_PER_MINUTE` | `20` | عدد الطلبات المسموح بها لكل مستخدم في الدقيقة |
| `COOKIES_FILE` | — | مسار ملف كوكيز، يفيد إذا يوتيوب حظر السيرفر |
| `YTDLP_PROXY` | — | بروكسي، مثل `http://user:pass@host:port` |

## مشاكل شائعة

- **"يوتيوب حظر السيرفر مؤقتاً"**: يوتيوب يحظر عناوين IP حق السيرفرات كثير. الحلول بالترتيب:
  1. حدّث yt-dlp (`pip install -U yt-dlp`، أو أعد تشغيل الحاوية)
  2. استخدم ملف كوكيز من حساب يوتيوب عن طريق `COOKIES_FILE`
  3. استخدم بروكسي سكني عن طريق `YTDLP_PROXY`
- **التحميل ياخذ وقت قبل ما يبدأ**: هذا طبيعي في 4K و8K، لأن السيرفر يحمّل الصوت والصورة ويدمجهم أول، وبعدها يرسل لك الملف.

## الحماية

- يقبل روابط `http` و `https` بس، والمستخرج العام في yt-dlp مقفل، فما أحد يقدر يخلي السيرفر يفتح روابط داخلية (SSRF).
- فيه حد لعدد الطلبات لكل IP، وحد للتحميلات اللي تشتغل بنفس الوقت.
- كل ملف ينحذف من السيرفر بعد ما ينرسل.

## تنبيه قانوني

تحميل الفيديوهات ممكن يخالف شروط استخدام بعض المنصات، مثل يوتيوب وتيك توك. استخدم الموقع لتحميل المحتوى اللي تملكه أو المسموح بتحميله، واحترم حقوق أصحاب المحتوى. إذا نشرت الموقع للعامة، أنت المسؤول عن الالتزام بالأنظمة وقوانين حقوق النشر.
